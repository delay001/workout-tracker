# Трекер тренировок (PWA)

Личное приложение для записи силовых тренировок с телефона прямо в зале.
Пользователь один (я), сервера нет, все данные хранятся на телефоне.

## Как со мной работать

- Я не программист, я системный аналитик. Объясняй решения коротко и простыми словами.
- Перед крупной задачей сначала предложи план и дождись моего «ок». Мелкие правки делай сразу.

## Стек

- Vite + TypeScript, без UI-фреймворков (обычный DOM). Если без фреймворка станет совсем тяжело,
  предложи замену и объясни, зачем.
- Хранение: IndexedDB через библиотеку Dexie.
- PWA: манифест + service worker (vite-plugin-pwa), работает офлайн, ставится на главный экран Android.
- Хостинг: GitHub Pages (нужен HTTPS, чтобы PWA можно было установить).
- Интерфейс на русском и английском, все тексты живут в `src/i18n/`. План развития: `docs/SPEC-v2.md`.
  Mobile-first, темная тема, крупные кнопки: в зале руки заняты и в мелу.

## Команды

- `npm run dev`: локальный запуск
- `npm run dev -- --host`: открыть с телефона в той же Wi-Fi сети
- `npm run build`: сборка
- `npm test`: тесты (Vitest) для логики: расчеты, импорт/экспорт, миграции данных

## Экраны

Три вкладки внизу, на экране записи тренировки они скрыты. Настройки открываются по нажатию на аватар
(он есть на каждой вкладке):
- **Тренировка**: кнопка «Новая запись», затем выбор даты и типа. Если есть активная тренировка, вместо нее
  кнопка «Активная тренировка»: из активной можно выйти и вернуться, вторую начать нельзя.
- **История**: календарь и список тренировок, переключатель на упражнения с лучшими результатами и графиком,
  на вес тела и на замеры.
- **Статистика**: период (месяц, 3 мес, полгода, год), цель месяца, тренировки, тоннаж, подходы и время за период,
  разбивка по типам, тоннаж по месяцам; отдельно «Мышцы».
- **Настройки** (через аватар): группы «Профиль», «Внешний вид», «Тренировки», «Данные».

## Модель данных

- **Упражнение**: название, группа мышц (необязательно), заметка, отметка «скрыто из каталога».
  Названия свободные: «Жим лежа», «Тяга верхнего блока», «Hammer тяга сверху».
- **Тренировка**: дата, тип (верх / низ / кардио / другое или свой из настроек), длительность (вводится вручную), оценка от 1 до 10, заметка, список упражнений.
- **Подход**: вес (кг, шаг 0.5; упражнения со своим весом записываются с весом 0), повторения,
  отметки «разминочный» и «в отказ».
- **Вес тела**: дата, кг.
- **Замеры** (позже): дата, шея, талия, грудь, бедра, бицепс Л/П, предплечье Л/П, бедро Л/П, икра Л/П.

Запись пишу, например, так: «Тяга верхнего блока 66x8, 73x8, 79x6».

## MVP (версия 1)

1. Начать тренировку: выбрать дату (по умолчанию сегодня) и тип → добавить упражнение → вносить подходы.
   По нажатию на поле открывается каталог упражнений по группам мышц, ввод текста его фильтрует и находит
   упражнение и по старым названиям. Можно создать свое. Группа мышц подставляется сама, ее можно поменять.
2. Во время ввода подхода показывать, **что я делал в этом упражнении в прошлый раз**: пиковый подход
   (максимальный вес, при равном весе больше повторений, разминочные не считаются).
   «Прошлый раз» определяется по дате тренировки, а не по времени внесения. Это главная функция приложения.
3. Быстрый ввод подхода: у первого подхода упражнения поля пустые, дальше подставлены вес и повторения
   предыдущего подхода этой тренировки. Кнопки +/− (шаг 0.5 кг), вес можно ввести и вручную.
4. Завершить тренировку, список прошлых тренировок, открыть и отредактировать любую.
5. Простой календарь: за месяц, дни с тренировками отмечены, по нажатию на день открывается тренировка.
6. История по упражнению: все подходы по датам, лучший результат (максимальный вес в подходе, разминочные
   не считаются; при равном весе лучше тот, где больше повторений).
7. **Экспорт и импорт всех данных в JSON-файл.** Обязательно: данные браузера на телефоне могут стереться,
   резервная копия — единственная защита. Импорт полностью заменяет текущие данные, перед этим предупреждение.

## Версия 2 (после MVP)

- Шаблоны тренировок «Верх» и «Низ»: заранее заданный список упражнений.
- Личные рекорды: отмечать, когда побит рекорд (по весу и по расчетному 1ПМ, формула Эпли).
- Отдельная вкладка с лучшими результатами по упражнениям.
- Журнал веса тела и график.
- Импорт старых записей из текста формата «Упражнение 66x8, 73x8, 79x6».

## Версия 3

- Замеры тела и их динамика.
- Графики прогресса по упражнению.
- Статистика: сколько тренировок верха и низа за месяц, тоннаж.

## Критерии готовности MVP

- Ставится на телефон с GitHub Pages как приложение и запускается без интернета.
- Тренировку из 6 упражнений по 3–4 подхода можно внести одной рукой, не больше ~3 нажатий на подход.
- После перезапуска телефона данные на месте; экспорт → удаление данных → импорт возвращает все.

## Бэклог

(сюда агент дописывает идеи, которые всплыли по ходу)

### Сначала: надежность данных

- Напоминание о копии: показывать, сколько дней назад она делалась, и просить обновить через 7 дней.
- Перед импортом файла предлагать сохранить текущую копию, потому что импорт заменяет все.
- Отмена только что удаленного подхода, упражнения или тренировки (плашка «Отменить» на несколько секунд).
- Отмена импорта старых записей: сейчас убрать их можно только по одной или из копии.
- Показывать в настройках, разрешил ли браузер постоянное хранение.
- Предложение сделать копию перед изменением структуры базы (раздел 4 ТЗ), нужно при следующей миграции.

### Удобство в зале

- Таймер отдыха после записи подхода, с вибрацией по окончании.
- Экран не гаснет во время тренировки (Wake Lock).
- Кнопка «Повторить тренировку»: начать новую с упражнениями прошлой такой же.
- Заметка к упражнению или подходу: «болит колено», «поменять хват». Поле у упражнения в модели уже есть.
- Суперсеты: объединять два упражнения в тренировке.
- Менять порядок упражнений в начатой тренировке.
- Быстрые кнопки для веса: последние использованные значения.
- Выбор упражнений карточка за карточкой: кнопка «Следующее упражнение» после последнего подхода.
- Длинные экраны: кнопки завершения и добавления закреплять внизу, чтобы не листать.

### Статистика и данные

- Точный прирост силы за месяц: на сколько вырос 1ПМ по основным упражнениям.
- Сравнение двух месяцев рядом.
- Календарь-тепловая карта за год, как у GitHub.
- Минуты кардио в статистике: сейчас время считается только по длительности тренировок.
- Экспорт в CSV для таблиц.
- Найти и объединить дубли упражнений, в том числе после импорта.
- Сверить пороги уровней с настоящим источником: сейчас значения приблизительные.

### Доделки по ТЗ

- Зеленый и красный цвет в сравнении замеров в зависимости от цели (F9).
- Фото прогресса (F9), вопрос 1 раздела 6.
- Отдельные поля профиля в настройках: возраст, опыт, цель. Сейчас только через повторное знакомство (F16).
- Перевод названий каталога и групп мышц на английский (F15). Группы мышц: перейти с 8 общих на 14 из справочника.
- Предупреждение о темпе цели показывать в выбранных единицах, а не всегда в кг.
- Разбор старых записей на английском языке.
- Значение «как считается» у каждого показателя: 1ПМ, тоннаж, тренд.

### Качество кода

- Вынести повторяющиеся списки по группам и выбор месяца в общие функции: сейчас они написаны в нескольких экранах.
- Проверки экранов в браузере автоматическими тестами: сейчас тестами покрыты только расчеты.
- Настроить запуск тестов при публикации, чтобы сломанная версия не попала на сайт.

### Дизайн

- Кольцо прогресса к цели месяца, серия недель с тренировками, конфетти при рекорде, вибрация при записи подхода,
  таймер отдыха с анимацией, карточка итогов тренировки.
- Человечный текст в числах: «3 тренировки», а не «тренировок 3» (склонения).
- Заменить стандартные окна подтверждения на свои в стиле приложения.
- Пустые состояния с подсказкой, что делать дальше.
- Силуэт карты тела нарисовать аккуратнее: сейчас он из простых фигур.

### Идеи, которые были раньше

- Шаблоны: менять порядок упражнений перетаскиванием.
- Справочная информация о приложении, доступная в настройках: как устроены разделы и как считаются показатели.
- Блок «В прошлый раз»: подумать, что и как лучше показывать. Сейчас только пиковый подход, раньше были все подходы.
- RIR (повторений в запасе) у подхода: поле убрано из ввода по просьбе пользователя, в модели данных осталось.
- Автоматический подсчет длительности тренировки (сейчас вводится вручную).
- Автоматическая резервная копия: скачивать файл при завершении тренировки. Незаметно перезаписывать один
  файл PWA на Android не может, поэтому файлы будут копиться в «Загрузках». Копия в Google Диск возможна,
  но требует входа в аккаунт и усложняет приложение.
