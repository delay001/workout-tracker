## 1. Термины

| Термин | Значение |
|---|---|
| Рабочий подход | Подход без отметки «разминочный» |
| Тоннаж | Сумма вес × повторения по рабочим подходам |
| 1ПМ (расчётный) | Максимум на 1 повторение по формуле Эпли: `вес × (1 + повторения / 30)`; для 1 повторения = вес. Считаем только по подходам до 12 повторений |
| Объём группы мышц | Число рабочих подходов на группу за неделю (пн–вс). Основная мышца упражнения = 1 подход, вспомогательная = 0,5 |
| Верх / низ | Тип тренировки из MVP |
| Толкающие / тянущие | Тип движения упражнения: жимы — толкающие, тяги и сгибания — тянущие |

## 2. Функциональные требования

### F1. Цветовые темы интерфейса
- Выбор темы в настройках: тёмная (по умолчанию), светлая, «как в системе» + выбор акцентного цвета (не меньше 6 вариантов).
- Тема применяется сразу, без перезагрузки, и сохраняется между запусками.
- Реализация через CSS-переменные; в компонентах никаких «зашитых» цветов.
- **Готово, когда:** все экраны читаемы во всех темах (контраст текста не ниже WCAG AA), выбор сохраняется после перезапуска.

### F2. Отметка рекорда во время подхода
- При сохранении подхода проверять, побит ли рекорд упражнения:
  - по весу при том же или большем числе повторений;
  - по расчётному 1ПМ;
  - по числу повторений с этим весом.
- Показать заметную плашку: «🔥 Новый рекорд: 36×8 — Жим гантелей на наклонной» + тип рекорда, лёгкая вибрация.
- Разминочные подходы рекордами не считаются. Первый подход в новом упражнении — не рекорд (нечего сравнивать).
- В истории подход-рекорд помечен значком.
- При редактировании или удалении подхода рекорды пересчитываются.
- **Готово, когда:** рекорд срабатывает в 3 описанных случаях, не срабатывает на разминке и первом подходе, корректно пересчитывается после правки.

### F3. Расчётный 1ПМ и график
- В карточке упражнения: текущий расчётный 1ПМ (лучший за последние 4 недели) и лучший за всё время.
- График 1ПМ по датам (одна точка на тренировку — лучший подход), периоды: 1 мес / 3 мес / год / всё.
- Показатель «сила от пика»: текущий 1ПМ в процентах от исторического максимума.
- **Готово, когда:** значения совпадают с ручным расчётом на тестовых данных, график переключает периоды.

### F4. Баланс верх / низ
- На главном экране / в статистике: количество тренировок верха и низа за выбранный период (по умолчанию 4 недели) и их соотношение.
- Предупреждение, если за последние 14 дней не было ни одной тренировки низа или соотношение хуже 3:1 (порог настраивается).
- **Готово, когда:** счётчик совпадает с историей, предупреждение появляется и исчезает по правилам.

### F5. Объём по группам мышц и баланс толкающих / тянущих
- У каждого упражнения: основная группа мышц, вспомогательные группы (0–3), тип движения (толкающее / тянущее / другое).
- Группы мышц (справочник): грудь, спина (широчайшие), спина (верх / трапеции), плечи (передняя, средняя, задняя дельта), бицепс, трицепс, предплечья, квадрицепс, бицепс бедра, ягодицы, икры, пресс.
- Экран «Неделя»: объём по каждой группе (подходы, см. термины), сравнение с прошлой неделей.
- Соотношение толкающих и тянущих подходов за неделю.
- Для уже созданных упражнений — экран, где я быстро проставляю группы.
- **Готово, когда:** объём на тестовой неделе совпадает с ручным подсчётом, включая вспомогательные мышцы по 0,5.

### F6. Статистика по упражнениям и «давно не делал»
- Список «Давно не делал»: упражнения, которых не было N дней (по умолчанию 21, настраивается), с количеством дней.
- Карточка упражнения:
  - сколько раз выполнялось, дата первого и последнего раза;
  - лучший подход, лучший 1ПМ, максимальный тоннаж за тренировку;
  - график рабочего веса и тоннажа;
  - полная история подходов по датам.
- Общая статистика: тренировок, часов в зале и тоннажа за неделю / месяц / год; топ упражнений по частоте.
- **Готово, когда:** все цифры совпадают с историей на тестовых данных.

### F7. Журнал веса тела с трендом
- Ввод веса: дата (по умолчанию сегодня), кг с шагом 0,1. Одна запись в день (повторный ввод заменяет).
- График: точки замеров + линия тренда (скользящее среднее за 7 дней по имеющимся замерам).
- Изменение тренда за неделю и за месяц в кг.
- **Готово, когда:** тренд совпадает с ручным расчётом, пропуски в днях не ломают график.

### F8. Цель по весу с дедлайном
- Цель: целевой вес + дата. Одна активная цель, завершённые хранятся в истории.
- Показывать: сколько осталось кг и дней, нужный темп (кг в неделю), фактический темп по тренду за 2 недели, статус «укладываюсь / отстаю / опережаю».
- Цель на графике веса — горизонтальная линия, дедлайн — вертикальная.
- Предупреждение, если нужный темп больше 1 кг в неделю (слишком агрессивно).
- **Готово, когда:** расчёты верны на тестовых данных, статус меняется при смене темпа.

### F9. Замеры тела и сравнение дат
- Замеры: шея, грудь, талия, бёдра (ягодицы), бицепс Л/П, предплечье Л/П, запястье, бедро Л/П, икра Л/П (см). Любое поле можно не заполнять.
- Отметка у бицепса: «в напряжении / расслабленный».
- Сравнение двух выбранных дат рядом: значения и разница (зелёный / красный в зависимости от цели).
- График по каждому замеру.
- Фото прогресса (необязательно, см. открытые вопросы): хранятся только на устройстве, в экспорт не попадают без явного выбора.
- **Готово, когда:** сравнение двух дат показывает верную разницу, пустые поля не ломают экран.

### F10. Нормы объёма и рекомендации
- Для каждой группы мышц — целевой диапазон рабочих подходов в неделю (по умолчанию 10–20, у мелких групп свои значения; все пороги редактируются в настройках).
- Статус группы: «мало / в норме / много».
- Рекомендации перед тренировкой: «Ноги: 4 подхода из 10 на этой неделе — добавь упражнение на квадрицепс» и предложение конкретного упражнения из моей истории.
- Приложение **не меняет программу само**, только предлагает; принять — одной кнопкой.
- **Готово, когда:** статусы считаются по порогам, рекомендация предлагает упражнение нужной группы.

### F11. Тепловая карта тела
- Силуэт тела (вид спереди и сзади, SVG), мышцы закрашены по недельному объёму из F5 относительно норм из F10: серый — 0, далее шкала от «мало» к «в норме» и «много».
- Нажатие на мышцу — объём, упражнения за неделю.
- Переключатель «эта неделя / прошлая / среднее за 4 недели».
- Силуэт рисуется своими силами (простые фигуры), без чужих защищённых изображений.
- **Готово, когда:** цвета соответствуют статусам из F10, нажатие показывает детали.

### F12. Уровень по упражнению
- Для базовых упражнений (жим лёжа, присед, становая, жим стоя, подтягивания, румынская тяга) — уровень по отношению 1ПМ к весу тела: новичок / начальный / средний / продвинутый / элита.
- Пороги хранятся в таблице-справочнике в коде, её легко поправить. Источник порогов — см. открытые вопросы.
- Показать, сколько не хватает до следующего уровня в кг.
- Учитывать мой текущий вес по тренду из F7.
- **Готово, когда:** уровень пересчитывается при изменении 1ПМ и веса тела.

### F13. Ачивки
- Типы ачивок:
  - регулярность: N тренировок в месяц (8, 10, 12), N недель подряд с планом;
  - время: N часов в зале за месяц (10, 15, 20);
  - тоннаж: за тренировку, за месяц;
  - рекорды: первый рекорд, 10 рекордов, 50;
  - вехи: 10 / 50 / 100 / 250 тренировок;
  - вес: достижение цели из F8.
- Месячные ачивки можно получать каждый месяц (с счётчиком «×3»), разовые — один раз.
- Уведомление-плашка при получении; экран «Ачивки» с полученными и закрытыми (с прогрессом «7 из 10»).
- Список ачивок задаётся конфигом, новые добавляются без изменения логики.
- **Готово, когда:** ачивки выдаются ровно один раз за условие, прогресс верен на тестовых данных.

### F14. Итоги года
- Доступны с 15 декабря до конца января и в любое время из меню для прошлых лет.
- 6–8 листаемых карточек: число тренировок и часов, общий тоннаж, любимое упражнение, самый большой прирост 1ПМ, рекорды за год, изменение веса тела, лучший месяц, баланс верх / низ.
- Каждую карточку можно сохранить картинкой.
- **Готово, когда:** карточки строятся на тестовых данных за год, сохранение картинки работает на Android.

### F15. Английский язык
- Все тексты интерфейса выносятся в файлы перевода (ru, en). В коде строк интерфейса нет.
- Язык: по системе при первом запуске, затем выбор в настройках.
- Названия упражнений, которые ввёл пользователь, не переводятся.
- Форматы дат и чисел — по выбранному языку.
- **Важно:** инфраструктуру переводов сделать в первом этапе, чтобы новые экраны сразу писались через неё.
- **Готово, когда:** переключение языка меняет все экраны, поиск строк кириллицей в коде компонентов ничего не находит.

### F16. Онбординг
- Показывается при первом запуске (и доступен повторно из настроек), 3–4 экрана, любой можно пропустить:
  1. Язык и тема.
  2. Цель: набор массы / сушка / сила / поддержание; текущий вес, рост, возраст; целевой вес и дата (создаёт цель F8).
  3. Опыт (новичок / 1–3 года / 3+), тренировок в неделю, обычная длительность.
  4. Сплит: верх/низ, фулбади, свой — с предложением готового шаблона.
- Введённые данные редактируются в профиле.
- **Готово, когда:** после онбординга заполнены профиль и цель, пропуск всех экранов не ломает приложение.

## 4. Изменения данных

- Упражнение: + основная группа мышц, вспомогательные группы, тип движения, базовое упражнение для уровней (да/нет).
- Новые сущности: вес тела (уже есть в MVP — проверить), цель, замер, ачивка (полученная), профиль, настройки (тема, язык, пороги).
- Миграция существующей базы IndexedDB без потери данных; экспорт / импорт JSON обновить под новые сущности.
- Перед миграцией приложение предлагает сделать резервную копию.

## 5. Нефункциональные требования

- Всё работает офлайн, данные не покидают устройство.
- Экраны статистики открываются быстрее 1 секунды при 2 годах истории (~300 тренировок) — проверить на сгенерированных данных.
- Графики — одна лёгкая библиотека на всё приложение (предложи варианты).
- Крупные элементы управления, работа одной рукой, как в MVP.
